# Car Booking API with MCP AI

A Python-based **Car Booking API** that integrates with **MCP AI** to manage car listings, bookings, and client interactions. Built as a backend service with Python, designed for easy extension and integration with frontend apps.

---

## Features

- List available cars dynamically  
- Book cars using API endpoints  
- Integrates with MCP AI for intelligent responses and client interaction  
- RESTful API design for easy consumption  

---

## Tech Stack

- **Backend:** Python  
- **AI Integration:** MCP AI  
- **API Framework:** FastAPI / Flask (if used)  
- **Database:** SQL or in-memory (depending on implementation)
